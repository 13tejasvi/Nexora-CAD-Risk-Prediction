# 🫀 Nexora: AI-Powered CAD Risk Assessment System

## Overview

Nexora is an AI-powered Clinical Decision Support System designed to predict the risk of Coronary Artery Disease (CAD) using Machine Learning.

The system analyzes patient clinical parameters and laboratory values and provides a CAD risk prediction along with probability-based risk categorization.

---

## Problem Statement

Coronary Artery Disease is one of the leading causes of mortality worldwide. Early risk assessment can help healthcare professionals identify high-risk individuals and support preventive healthcare decisions.

---

## Solution

This project uses a Random Forest Machine Learning model trained on the Z-Alizadeh Sani dataset to predict CAD risk based on patient information.

The application provides:

- Patient data entry interface
- CAD probability prediction
- Risk categorization (Low, Moderate, High)
- Patient summary report
- Clinical decision support

---

## Dataset

- Z-Alizadeh Sani Dataset
- Clinical and laboratory parameters related to Coronary Artery Disease
